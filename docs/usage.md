# 使用指南

## 安装、启动与退出

从 Releases 下载 Windows x64 ZIP，解压到固定位置后运行 `GlassTodo.exe`。首次正常启动默认设置当前用户登录自启；右键菜单可关闭。应用没有自动下载安装更新的功能。

右键「隐藏到托盘」只隐藏便签，本机 MCP 仍在运行；「退出」关闭窗口与服务。双击托盘图标可显示便签。请在退出或升级前保存正在编辑的正文和状态名称。

## 窗口

- 拖动标题栏空白区域移动。图钉切换置顶，箭头切换便签 / 浮条。
- 从四条边或四个角缩放。展开状态最小 316 × 366 DIP，随系统 DPI 缩放；最大尺寸适配所在显示器工作区。浮条保留紧凑尺寸，展开后恢复原便签尺寸。
- 拖到显示器工作区四边附近或越过边缘后松手，便签会收为 48 × 48 DIP 图标，避开任务栏。移入图标展开，移出后约 320ms 收回。
- 刚拖到边缘时，若鼠标仍在最终图标上，先移出再移入才会展开。展开后拖离边缘，可恢复普通便签。
- 编辑器、设置、状态选择或右键菜单使用期间保持展开。窗口位置、完整尺寸、贴边方向、置顶与浮条状态会保存。

## 记录和整理

点击添加区新建，双击正文或按 `F2` 编辑。正文支持多行；单条最多 16,384 个 Unicode 字符（Rust 标量值计数）。

新增时，用空行分隔多条：

```text
第一条事项
这里仍是第一条的补充说明

第二条事项

第三条事项
```

普通换行保留在同一条事项内。只含空格或制表符的行也视为空行；连续空行不会生成空待办。已有事项的编辑会整体保存为同一条，不按空行拆分。

点击圆点完成 / 恢复事项；点击状态标签打开选择浮层。拖动活动事项正文排序。滚轮浏览列表；长正文输入框也支持滚轮和原生垂直滚动条。

垃圾桶、右键删除或 `Delete` 执行软删除。`Ctrl+Z` 或底部「撤销删除」恢复最近一次删除，保留正文、实际状态和排序；撤销记录跨重启保留。完成区展开后仍可恢复和删除事项。

## 快捷键

| 场景 | 按键 | 行为 |
| --- | --- | --- |
| 便签 | `Ctrl+N` | 新增 |
| 便签 | `F2` | 编辑选中的事项 |
| 便签 | `Delete` | 删除选中的事项 |
| 便签 | `Ctrl+Z` | 撤销最近删除 |
| 便签 | `Ctrl+,` | 设置 |
| 输入框 | `Enter` | 提交新增 / 保存编辑 |
| 输入框 | `Shift+Enter` | 插入换行 |
| 输入框 | `Esc` | 取消 |
| 输入框 | `Tab` | 切换提交 / 取消控件 |
| 状态浮层 | `↑` / `↓`、`Home` / `End` | 选择状态 |
| 状态浮层 | `Enter` / `Esc` | 确认 / 关闭 |

中文输入法组合期间，确认候选的 Enter 不会被当作保存快捷键。

## 外观和自定义状态

齿轮 → 设置 →「外观」支持系统 / 浅色 / 深色、60–100% 背景遮挡、12–18 DIP 字号和 8–32 DIP 圆角。背景遮挡不改变文字和图标的不透明度。外观实时预览并自动保存。

「状态」页支持新增、重命名、颜色和归类。名称长度为 1–10 个 Unicode 字符，最多 24 个状态（包括 3 个内置项）。自定义状态归入未完成 / 进行中 / 已完成之一；归入已完成时进入完成区。三个内置状态固定。

界面删除自定义状态需要再次点击确认，相关事项会转为未完成，正文保留。MCP 删除可显式指定替代状态。新安装不会自动添加「发布测试」等自定义示例。

## 数据、备份与升级

默认数据目录：`%LOCALAPPDATA%\GlassTodo`。

| 文件 | 用途 |
| --- | --- |
| `todos.sqlite3` | 事项、状态定义、外观和窗口配置 |
| `mcp-token.txt` | 本机 MCP 访问密钥 |
| `mcp-configs/` | 含真实密钥的客户端配置示例 |
| `app.log` | 启动 / 绘制错误诊断 |

备份前保存所有编辑并正常退出，再复制整个数据目录。恢复时关闭应用，用自己的备份恢复该目录。备份也包含密钥和私密内容，应保存在受控位置。

升级时正常退出旧实例，然后替换 EXE；不要覆盖数据目录。维护者可使用 `GlassTodo.exe --quit` 请求同端口 GUI 实例正常退出，但应先保存编辑。`--quit` 不控制纯 headless 实例。

## 启动参数

| 参数 | 用途 |
| --- | --- |
| `--data-dir PATH` | 使用独立数据目录 |
| `--port PORT` | 使用其他本机 TCP 端口，默认 57841 |
| `--no-autostart` | 本次 UI 启动不启用登录自启 |
| `--headless` | 同一数据 MCP 服务，不创建便签窗口 |
| `--exit-after SECONDS` | 到期正常停止，供自动化 / 测量使用 |
| `--quit` | 请求同端口 GUI 实例退出 |
| `--help` | 显示参数 |

本机 agent 接入见 [MCP 文档](mcp.md)。出现问题先查看 [排查指南](troubleshooting.md)。
